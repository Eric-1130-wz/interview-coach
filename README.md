# 面试陪练官（interview-coach）

> 一个 TeleAgent skill：高仿真模拟面试 + 弱项攻坚 + 跨场次进步追踪。不代写答案，只陪你练。

## 30 秒上手

| 你说 | 它做什么 |
|------|---------|
| "帮我练一场字节后端校招面" | 完整模拟：面试官人设开场 → 追问下钻 → 结束出六维评分复盘报告 |
| "面试官问我为什么离职，我该怎么说？" | 单题快练：五分钟给答法（结构占位，不代写成稿） |
| "我项目数字没准备好怎么办，明天就面字节了" | 面试前急救包：三个故事压到 60 秒 + 一页急救卡存手机 |
| "我专练项目证据表达" | 切片对练：3~5 回合一洞到底，每回合注解"面试官在听什么"+更稳的说法 |
| "刚面完美团，感觉不好" | 真实面试复盘：红旗排查 + 结果回填进日志 |

场景覆盖：校招（技术面/群面/AI面）、保研（夏令营/预推免/导师约谈/套磁）、考研复试、国企（国网/烟草/铁路）、考公考编（结构化/结构化小组/无领导/教师编试讲）、社招转行。

## 三个技术亮点

1. **三层追问决策**——面试官不是按题库念题，而是听你上一句答了什么再决定追问什么：数字核实（"一万多用户是注册量还是日活？"）→ 万能药质疑（"加缓存能解决你说的连接池打满吗？"）→ 瓶颈定位（"瓶颈在应用还是数据库？怎么定位到的？"）。追问跟得上一个数字，而不是一个话题。
2. **跨会话弱项状态机**——练习记录落 `interview-log/log.json`，由 `scripts/log_manager.py` 管理（纯标准库）：per-weak 独立计时（今天练证据明天练结构，互不清零）、攻克可复发（预警/已复发/持续恶化四级）、原子写 + 损坏熔断 + 交叉校验。进步不靠 AI 记性，靠数据。
3. **真实结果校准**——真实面试的 pass/fail 回填进日志后，summary 分桶输出"模拟 A 级 2 场：1 过 1 挂"（模拟与真实面试分开统计）与 fail 归因（挂掉的场次里哪个维度最常拖底）——模拟分到底准不准，用你自己的真实结果验证。

## 诚实限制（先看这个再决定用不用）

- 文字模拟测不了：真实语速、发音、镜头感、板书书写；时长按字数估算（200 字/分钟）+ 用户自报校准
- 打字可以删改、真考场不行——开场即约束"一次发完"，补答标注轻扣，但这只是补偿不是消除
- 具体学科结论（变压器并联条件、课标要求等）模型不下断言，只给"查哪本规范"的路径——防似是而非的专业点评
- 留学面/教职/竞聘等场景无专项模块，命中时明说并给兜底方案
