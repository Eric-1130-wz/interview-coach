# 国企专项（国网 / 烟草 / 铁路 / 电网 / 中烟 / 地铁等）

> 题库时点：2026-11。招聘流程与题型结构稳定；各单位当年招聘公告（专业科目、面试轮次）以当年公告为准。

国网、烟草、铁路局、地铁等国企招聘面试**不是公务员结构化**：不用五大类题本、没有宣读引导语的规程，而是半结构化 + 专业题为主。用户说"国网/烟草/铁路/电网/国家电网/中烟"时走本文件，不走 civil-service.md。

## 面试形态

- 轮次：常见"笔试 → 一轮面试（1 对多考官）"，部分加二轮（人力 + 专业分开面）。
- 形态：**半结构化**——自我介绍 + 专业题为主 + 综合素质题为辅，考官可自由追问（这点与公务员结构化的零互动相反）。
- 考官组：专业考官（部门技术骨干）+ 人力考官（看稳定性与政治素养），两类考官出题口径不同。

## 流程（15–25 分钟）

自我介绍（1–2 分钟，国企偏好：政治面貌、学生干部经历、成绩排名、生源地）→ 专业题 2–4 道 → 综合素质题 2–3 道 → 追问（简历细节）→ 反问

## 题库

### A. 专业题（按报考专业出，专业对口是硬指标）

| 岗位类别 | 典型题目 | 追问 |
|---------|---------|------|
| 电气类（电网主力） | 变压器并联运行的条件？中性点接地方式有哪些、适用场景？ | "现场遇到 XX 情况你怎么判断？" |
| 计算机/通信 | 讲一下你做过的项目用什么架构，为什么 | "数据量大了怎么办""和现网系统怎么对接" |
| 财务/会计 | 三张表的勾稽关系；收入确认的条件 | "利润好现金流转负，什么问题" |
| 管理/综合 | 一份报表/流程里有漏洞你怎么发现 | "发现了之后向谁报" |

- 专业题要求：从用户简历里的课程与项目出发出题，不确定其专业课时直接问"你主修哪几门核心课"，围绕其答案出。
- 答不出专业题的处理：降级到更基础的同主题题（同考研复试阶梯出题法），探出边界即可，国企面试对专业基础的容忍度低于对诚实的容忍度。
- **专业题点评边界（本场景高风险）**：电气/计算机/财务类学科结论按 SKILL.md 专业正确性守则执行——模型对"变压器并联运行条件""三张表勾稽"等具体学科结论不全部可靠，点评不确定时只给判断路径（"这个结论请对照〈电机学〉教材第 X 章核实"），不下断言；绝不能让用户把可能错的框架当标准答案背走。

### B. 综合素质题（稳定性是隐形第一考点）

1. 为什么选择我们单位/回到家乡？→ 追问："父母支持吗？他们做什么的？"
2. 能接受基层县公司/轮岗/一线站段/倒班吗？→ 追问："三年内可能都在县里，你确定？"
3. 你是党员吗？为什么入党/怎么看入党初心？（政治素养，如实回答，非党员就说积极递交申请的状态）
4. 学生干部经历里最难的一件事？
5. 你还报了哪些单位？如果我们和 XX 同时要你？（与保研优营同款题，考察诚意）

### C. 压力 / 情境题

1. 领导安排你干一件你认为不合规的小事，怎么办？（既不能扛上也别硬顶）
2. 老师傅说"你们大学生来了也干不了啥"，怎么接？
3. 抢修任务春节不能回家，家里有事，怎么处理？

### D. 反问环节

- 好反问：入职后头一年的培养安排、有没有导师制、这个岗位的实际工作地点
- 减分：问"轻松吗""加班多吗"（国企面试问这个几乎必挂）

## 半结构化追问链（本场景核心装备——国企考官可自由追问，追问密度介于结构化零互动与大厂业务面之间）

四段式推进，任一环含糊即停住下钻；一段打穿再换下一段，不并行多题：

| 段 | 主题题 | 追问链（每层一环） |
|----|--------|-------------------|
| 1. 专业 | "变压器并列运行要满足哪些条件？" | 答对 → "现场如果两台变比差 0.5% 会发生什么？你怎么发现的？"（理论→现场情境）；答错 → 降级同主题基础题探边界 |
| 2. 现场情境 | "变电站值班发现表计异常，你第一步做什么？" | "先操作还是先汇报？依据是什么？"→"如果规程和师傅经验冲突，听谁的？" |
| 3. 岗位适配 | "这个岗要下基层站段轮岗一年，你怎么看？" | "站段条件比你想的苦，具体哪里苦你说说？"→"同学都去了互联网，你为什么来这？" |
| 4. 稳定性 | "能接受三年都在县公司吗？" | "父母怎么看？他们做什么的？"→"对象/朋友在不在本地？"→"如果五年没调回市里，你会怎么办？" |

追问要领：专业段下钻看"会不会用"（不是背条件，是现场怎么办）；情境段看规程意识（先汇报）；适配段看真实意愿（口是心非一追就露）；稳定性段层层逼近但不逼到对抗。B 类综合素质题的追问链按本表 3/4 段执行。

## 出题策略

- 按单位类型微调：电网/铁路偏硬专业题 + 安全意识；烟草偏综合 + 财务纪律；地铁偏应急处置。
- 生源地与稳定性必出至少一题（B1/B2）。
- 模拟时声明半结构化：可以追问、可以就简历细节自由聊，语气介于公务员的规程感与大厂业务面之间。

## 本场景评分侧重（六维，见 scoring-and-feedback.md）

岗位匹配 30%（专业对口 + 稳定性 + 政治素养）、内容质量 25%、证据 15%（证书/成绩/干部经历的支撑物）、逻辑结构 15%、语言表达 10%、临场应变 5%。
重点观察：专业基础扎实度、稳定性信号是否坚定、对基层一线的态度是否真实（口是心非一追问就露）。
