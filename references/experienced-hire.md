# 社招 / 转行面试

> 题库时点：2026-11。追问链与考察点稳定；薪资行情、行业热点题按用户目标行业当年情况现场更新。

## 面试官人设

- **用人部门负责人**：务实高效，围绕"你能不能快速上手"提问，项目追问极其深入，警惕包装过度者。
- **HR 面**：聚焦稳定性、薪酬期望、离职原因，问题看似随和实则处处是钩子。
- **总监/高管面**：格局与动机考查，问题简短但空间大。

模拟时默认用人部门负责人面，节奏比校招更快、更硬。

## 典型流程（6~8 题；文本模拟可分段续场）

自我介绍（3 分钟版，重业绩）→ 项目深挖（核心，占半场以上）→ 专业能力 → 动机与稳定性 → 薪资与到岗 → 反问

## 题库

### A. 项目深挖（五段式追问链，核心武器）

对用户简历中每一个项目按以下链条推进，任一环含糊即停下追问：

```
1. 背景：这个项目解决什么问题？立项时的目标是什么？
2. 角色：团队多大？你具体负责哪块？谁向谁汇报？
3. 难点：最难的一个技术/业务决策是什么？当时有几个选项？为什么这么选？
4. 结果：量化结果？同比/环比如何？这个数字怎么统计的？谁背这个 KPI？
5. 复盘：如果重来，哪一步你会改？有什么遗留问题？
```

质疑式追问（严格型选用）：
- "这个增长有多少是大盘带来的，多少是你个人的贡献？"
- "听下来你更像执行者，策略是谁定的？"
- "这个方案失败了的话，责任怎么划分？"

### B. 专业能力题

- 按 JD 的 required skills 逐项出题：一题考察深度（原理/权衡），一题联系用户经历考察落地。
- 快问快答 3~5 个基础概念题校验知识面（用户项目涉及的技术栈）。
- 情境设计题："给你 X 资源，从 0 到 1 做 XX，前三个月你干什么？"

### C. 稳定性与动机

| 题目 | 追问链（钩子） |
|------|--------|
| 为什么离开上一家公司？ | "上一份工作里领导给你最多的一次负面反馈是什么？"（检验是否甩锅） |
| 为什么看我们这个机会？ | "你对我们的了解就这些？说说我们跟竞品的差别。" |
| 你的职业规划？ | "这个规划跟这个岗位好像不完全匹配，你怎么解释？" |
| 一年内换过两份工作，说说原因？ | 压力版："说实话，我们担心你半年后又走了。" |
| 你最不能接受什么样的领导/文化？ | 追问真实雷点，判断文化匹配 |

### D. 转行专属

1. 为什么转行？原行业做不下去了还是新行业更热爱？→ 追问："原行业回暖给你涨薪 50% 回去吗？"
2. 转行做了哪些准备？→ 追问具体行动（课程/项目/证书），"一直在学"这类回答一律追问成果与时长。
3. 能力迁移：过去的经验哪部分对这个岗位有用？哪部分是负资产？
4. 降薪/降级准备：转行初期可能从执行岗/低级别做起，可以接受吗？
5. 压力题："你的年龄/年限在新领域跟应届生竞争，优势到底是什么？"

### E. 薪资与到岗

1. 当前薪资构成？期望薪资？（追问：base 与奖金比例、期权怎么看待）
2. 给不到你的期望，最高只能给 X，你怎么考虑？
3. 多久能到岗？→ 追问："现公司交接要多久？会不会被挽留？"
4. 手上有其他 offer 吗？怎么排序？

### F. 空窗期应对

- 背景任选 3~6 个月空窗："这段时间你在做什么？"→ 追问每月安排、学习成果、为什么还没定下来。
- 考察点：是否有规划、是否坦诚、空窗期产出能否自证。

### G. 管理岗可选模块（应聘管理岗时启用）

1. 团队多少人？怎么做绩效排名？末位怎么处理？
2. 招人标准？裁过人吗？说说过程。
3. 向上管理：和上级意见冲突最激烈的一次？
4. 你离职后，团队谁接班？为什么是他？

### H. 反问环节判断

- 好问题：岗位当前最大挑战、前任/团队现状、考核标准、业务优先级
- 减分问题：试用期被辞退概率、只问加班福利、暴露对公司业务完全不了解

## 真实面试复盘模块（触发词：刚面完 / 回来复盘 / 面试感觉不好）

用户从真实面试回来时不演面试官，切换教练模式复盘：

1. 让用户复述关键问答：考官问了什么、自己怎么答的、哪个瞬间感觉不对（有笔记或录音要点可直接粘贴）。
2. 逐题点评：这次答得怎么样、更稳的说法（对照六维与扣分点清单，重点抓证据维）。
3. 红旗排查：有没有致命失误（说错公司业务、薪资谈崩、贬低前司、谎报经历被戳穿）。
4. 给出结果预判区间 + 下一家的三条改进清单。
5. 落练习日志（mode 填"真实复盘"，passed 按是否出现致命失误判定，weak_point 取最大暴露弱项）。**必带 outcome 字段**：面试过了=pass、挂了=fail、结果未出=pending；结果出来后回来运行 backfill 更新（`log_manager.py --workspace <工作区> backfill --session <场号> --outcome pass|fail`）。用户说明本场是为之前某几场模拟/急救包练的真实面试时，把同一 outcome 也 backfill 到那些场次——summary 的"模拟评级 × 真实结果"校准行由此积累，模拟分可信度用真实数据验证。
- 注意：真实复盘只基于用户转述，转述不全时明确说"以下判断依据你记得的部分"；不替用户虚构"面试官当时肯定在想 X"的确定结论。

## 出题策略

- 有 JD 时按 B 类优先定制，占题目一半以上。
- 项目经历丰富的用户，A 类深挖一个项目完整打穿链条，优于浅问多个。
- 严格型面试中，对"我负责了很多"这类揽功表述必须用数字核实与角色追问校验。

## 本场景评分侧重（六维，见 scoring-and-feedback.md）

岗位匹配 30%、证据 25%、临场应变 15%、内容质量 10%、逻辑结构 10%、语言表达 10%。
重点观察：量化叙事、决策思考深度（讲得出为什么）、稳定性风险信号、薪资谈判姿态（不卑不亢）。
