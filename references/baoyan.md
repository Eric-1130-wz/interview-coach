# 保研推免面试（夏令营 / 预推免 / 九推）

> 题库时点：2026-11。流程与形态（六种面试形态、套磁、零科研分支）长期稳定；优营比例、材料要求等细节各校每年微调，以目标院校当年招生简章为准。

保研与考研复试是两套几乎不重叠的体系，本文件只服务保研；考研复试见 graduate-admission.md。

## 时间线与机制（出题与压力题的背景板）

- **夏令营（5–7 月）**：报营 → 入营（看排名/英语/科研/竞赛）→ 营内考核 → **优营** ≈ 拟录取资格或加分。同期能拿多个营，9 月才需真正承诺。
- **预推免（9 月上中旬）**：夏令营没落定者的第二次机会，考核更紧凑（常半天内笔试+面试）。
- **九推（9 月 28 日国家推免系统）**：填志愿、发待录取；此前一切口头承诺在这天兑现或作废，也是候补捡漏的时刻。

优营带来的独有压力题（诚信与排序考察）：
- "你拿了几个营的优营？如果我们和 XX 同时要你，你怎么选？"——考察诚信与真实意愿，策略是表达明确的优先级和理由，忌拍胸脯保证又鸽。
- "你导师联系情况怎么样？发过几个老师邮件了？"——坦诚联系情况但不卑不亢，导师间互相知道的概率不低。

## 六种面试形态

形态确认遵循 SKILL.md 配置确认总规则：整场最多一次、半句并入开场白（示例："你这轮面的是哪种形式——导师单聊、专家组轮询，还是有英文文献/机试？直接开考了。"）。用户已说明形态时不再问。

### 形态一：导师单独约谈（最常见）
- 30–60 分钟聊天式，可能视频可能面谈；**看似闲聊，每句都在评估**：读研动机、抗压、家庭支持、英文水平、是否同时海投导师。
- 高频聊天切口：本科过得怎么样、为什么选这个方向、家乡与家人对你读研的态度、最近读什么、作息如何。
- 杀手锏问题："你还联系了其他老师吗？"（每个导师都会问）/"如果我这边名额竞争很激烈，你怎么办？"（抗压+忠诚度）/"你打算读博吗？"（试探长期性，别为了讨好随口承诺）。
- 模拟要点：语气放松像聊天，但问题要环环相扣；对动机类回答必追一层"为什么"。

**导师约谈话语样板（聊天式的要领：没有面试腔、问题藏在闲聊里、追问轻但准——参照此密度）：**

```
导师：来了？坐。路上还好吧。我是做目标检测这块的，你简历里那个视觉项目，是你自己想做的？

你：是课程要求的，不过我自己加了个检测模块。

导师：哦？加了什么？效果怎么样？

你：加了个轻量化的检测头，mAP 提了大概两个点。

导师：两个点，数据集多大？自己标的？

你：用公开数据集，两千张。

导师：嗯。家里是哪的？父母对你读研什么态度？

你：XX 省的，都很支持。

导师：支持是嘴上说还是真支持？读研三年不怎么回家的。

你：他们本来就……

导师：（不逼，转下一切口）最近读什么文献？说说一篇。

你：（说论文，略）

导师：行。你还联系了其他老师吗？——如实说就行，这很正常。
```

样板要点：开场像迎接客人不像审讯；每个技术问题都跟一个"多大/怎么标的"式轻追问；家常问题出现在技术问题之间（评估家庭支持）；杀手锏问题永远在最后三分之一，且语气最松（"如实说就行"）；全程没有"请回答""下一题"这类面试腔。

### 形态二：专家组轮询
- 3–5 位考官各盯一个领域轮番发问：科研、专业课、英文、综合素质。
- 模拟要点：声明"左边这位老师问科研方向，右边这位问专业基础"，切换发问人设；每个领域 2–3 题后切换。

### 形态三：英文文献环节（保研特有，专业英语考核）
- 形式：给一段本领域英文文献摘要 → 朗读 → 用中文或英文概述 → 考官英文提问。
- **考核专业英语，不是语法**：读不懂的词可以问可以跳过，但必须抓得住主线（研究对象、方法、结论）。
- **材料来源优先级**：①用户自带（请用户粘贴一篇真实论文的题目+摘要，最真实）；②教学拟写材料——必须开场明示「以下是教学拟写材料，非真实文献，只练流程与概述，术语与数据不作知识校验」。不用凭空生成的文献内容考专业英语。
- 出题方式：材料定后先让读，再问"What is the main problem this paper addresses?""What method did they use?"
- 评的是：术语发音、扫读速度、概括准确度。语法错误不扣大分，沉默和跑题扣大分。

### 形态四：现场抽题答辩
- 抽专业课题号 → 准备 3–5 分钟 → 陈述 → 考官围绕陈述提问。
- 模拟要点：让用户抽题号（或随机给编号列表），题目从专业课核心考点出；追问围绕"你的依据是什么""换个条件还成立吗"。

### 形态五：无领导小组讨论（部分营有）
- 见 references/group-interview.md，按该文件规则执行。

### 形态六：机试后技术面（强计算机营常见）
- 流程：算法机试（ACM 风格或 LeetCode 风格）→ 按机试成绩进技术面。
- 技术面问法："机试第 X 题你用的什么做法？复杂度多少？""有没有更优解？""讲一个你最熟的项目。"——机试题追问密度高于项目题。

## 套磁邮件与导师回信模块

用户提"导师邮件/套磁/联系导师/写邮件给老师"时进入本模块。性质是书面辅导：给框架、点评用户的草稿，**不代写成稿**。

**套磁邮件三段式**：
1. 门牌号（两行说清是谁）：姓名+学校+专业+排名百分比 / 六级或英语分数 / 一句话匹配度（读过老师哪篇论文、做过什么相关东西）。
2. 为什么是您的组（两三句，必须具体到论文名或方向细节，忌"慕名已久"）+ 一句自己的匹配证据（课设/竞赛/代码复现）。
3. 轻行动：附件（简历+成绩单，命名"学校-姓名-专业.pdf"）+ 问能否进一步沟通。总长不超 250 词，不催、不谈条件。

三忌：群发模板痕迹（换了称呼没换内容）、附件命名随意、一天内连环追问。

**导师回信三档应对**（模拟时任选一档练接信）：
- 积极回复（"欢迎报考"/约谈话）：致谢+确认时间+提前精读其近两年论文两篇；约谈前备好三问（为什么选我们组、读研规划、能接受什么强度）。
- 礼节性回复（"欢迎报考，名额不确定"）：不押注单导，继续礼貌联系 2–3 位不同方向老师——导师们对多联系有共识，坦诚优于被发现隐瞒；保持跟进但不逼问名额。
- 已读不回：等 5–7 个工作日发一次跟进（附新进展：新成绩/新竞赛/新读的论文）；仍无回音即转目标，不发第三封。

时机：夏令营开放前 3–4 周发首波；预推免前补发一批（目标：没招满营的老师）；九推当天是候补抢位战，提前备好随时能发的最新版简历。

模拟方式：请用户粘邮件草稿 → 按三段式点评（结构/具体度/长度/附件礼仪）→ 用户自己改 → 再出一档导师回信练接信。改到能发即停。

## 零科研应答分支（大量保研生的真实状态，默认准备）

用户没有实验室经历时，"介绍你的科研经历"这类题的正确打开方式不是硬编，而是**转向 + 坦诚 + 证据**：

- 标准框架：「我没有进过实验室，这是我目前最明显的短板。我做过 XX 课程设计/竞赛（说清做了什么、用了什么方法、结果如何），从中学到了 XX；为了读研我最近在精读 XX 方向的论文，已经读完 X 篇。」
- 可用作证据的替代物：课程设计（有完整流程的）、数学建模/ACM 等竞赛、大学生创新项目、自学复现的项目（复现了一篇论文的代码）。
- 必然追问链："没科研你凭什么觉得自己适合读研？" → "你说在补论文，讲一篇你最近读的？" → "这篇论文的局限是什么？"——**第三层答不出很正常，答"第二遍还没读到那个深度"比装懂强**。
- 禁忌：把课程实验吹成科研、报没读过的论文名、把队友的成果说成自己的。

## 专业课与综合素质

- 专业课按报考方向出基础题（阶梯出题法：定义 → 原理 → 应用 → 前沿）。
- 材料核验追问：成绩排名的真实性（"排第几？前百分之几？"）、竞赛里你个人的贡献、论文若有则问作者位次与具体工作。
- 高频压力题："你这个排名（英语六级分数）在营里不占优势，我为什么选你？""如果今年优营给不了你，预推免你还会来我们这吗？"
- **专业结论点评边界**：学科具体结论（定理、机制、公式）按 SKILL.md 专业正确性守则——不确定时只给"查哪本教材/规范哪个章节"的判断路径，不下断言；英文文献环节的教学拟写材料已标注非真实文献，不据其输出学科结论。

## 本场景评分侧重（六维，见 scoring-and-feedback.md）

证据 20%、内容质量 20%、岗位匹配 20%、逻辑结构 15%、语言表达 15%、临场应变 10%。
重点观察：零科研坦诚度、论文阅读真实性（读没读过一问便知）、读研动机成熟度、联系多导时的诚信表达。
