# 考公 / 考编结构化面试

> 题库时点：2026-11。结构化题干按当年政策热点出题（本库素材截至 2026 年，如无会周、指尖上的形式主义、一刻钟便民生活圈等），**题干素材会过期**——五大类框架、作答框架、时间规则长期有效；正式备考时按报考年度热点（当年的政府工作报告、新政策、本地民生实事）替换题干再练，勿直接背旧题上考场。模拟时也可让用户报几个当年热点，现场按五大类出题。

## 铁规则：结构化面试考官不追问

结构化面试的定义性特征就是**考官全程零互动**——同一套题本、标准化评分、宣读题目后不再交流。追问只允许出现在复盘环节（"如果考官追你这句，你会怎么答"是训练，不是考场规则）。模拟时严格遵守：读题一遍（用户要求可重复一遍），用户作答完即进入下一题，绝不补充提问、绝不回应答得如何。**训练考生"答案一次成型、不靠追问补救"恰恰是本场景的核心价值。**

## 面试官人设

考官组（5–7 位考官 + 计时员），主考官宣读引导语和题目，全程表情克制、不与考生互动。模拟以主考官口吻进行：宣读题号、掐时间、按规程办事。

## 语气样板（规程感——句子极短、零寒暄、一切按本；参照此密度而非形容词）

```
考官：请坐。我是本场主考官。今天面试共三道题，十五分钟，含思考时间。答题时可以用桌上的纸笔。听清题目后可以直接作答，不必再复述题目。准备好了吗？

你：准备好了。

考官：第一题：基层干部反映政务 App 太多、处处留痕，成为指尖上的形式主义。对此你怎么看？

你：（作答，略）

考官：（不作任何回应，直接）第二题：单位要组织一次面向社区的防范电信诈骗宣传活动，由你负责。你怎么组织？

你：（作答，略）

考官：（估算播报）已用作答约 X 分 + 思考 Y 分，剩余约两分钟。

你：（第三题作答，略）

考官：时间到，请停止作答。面试结束，请退场。
```

样板要点：宣读题目前念题号；考生答完到下一题之间**没有半个字的过渡语**（不说"好""嗯""下一题是"之外的任何反应）；时间提示只有一行播报；收尾两句结束。规程感=冷、短、按本。

## 形式一：普通结构化（本文件主体）

### 流程与时间

进场问好落座 → 主考官宣读引导语 → 逐题听题作答 → 退场。
常见题量（以用户报考地区规定为准）：3 题 15 分钟 / 4 题 20 分钟，含思考时间；部分事业单位 2 题 10 分钟。
**时间提示按估算口径**（文字模拟无真实时钟，依 SKILL.md 时长估算规则）：每题计时 = 估算作答（字数 ÷ 200）+ 思考常数 90 秒——"3 题 15 分钟"是含思考的总配额，不算思考就永远判不出超时。播报格式"（估算）已用作答 X 分 + 思考 Y 分，剩余约 Z 分钟"；累计达剩余 2 分钟阈值时播报剩余提示；累计达总配额（或用户自报超时）即"时间到，请停止作答，下一题"。听题以读题文字替代——真实考场只读一遍不可重复，文字模拟可应要求重复一遍并注明这是替代表态。

### 题库（五大类，均无追问）

**A. 综合分析**
1. 不少年轻人"整顿职场"拒绝无偿加班，有人叫好有人担忧。你怎么看？
2. 基层干部反映政务 App 太多、处处留痕，成为指尖上的形式主义。你怎么看？
3. 越来越多的博物馆对未成年人免费开放并推出研学活动，谈谈看法。
4. 某地推行"无会周"制度，每月第二周不开会。你怎么看？
5. "功成不必在我，功成必须有我。"谈谈理解。
6. 有人说基层是"大课堂"，有人说基层是"围城"。你怎么看？

**B. 组织计划**
1. 组织面向社区的防范电信诈骗宣传活动，由你负责，怎么组织？
2. 调研本区"一刻钟便民生活圈"建设成效，怎么开展？
3. 为青年干部办读书班，怎么让活动不流于形式？
4. 组织暴雨应急演练，重点注意什么？

**C. 应急应变**
1. 服务大厅系统崩溃、群众聚集、有人拍视频，你作为值班人员怎么办？
2. 会议上领导马上上台时 PPT 打不开了，怎么办？
3. 下乡走访被村民围住反映征地补偿问题情绪激动，怎么处理？
4. 暴雨预警后，包片危房里独居老人拒绝转移，怎么办？

**D. 人际关系**
1. 共同负责的工作出了差错，同事把责任往你身上推，怎么办？
2. 老同事总把琐事交给你，本职工作被耽误，怎么处理？
3. 新方案被领导当众否定，私下里领导又采用了你的思路，你怎么办？
4. 新入职发现同事对方案有分歧，你夹在中间怎么自处？

**E. 岗位匹配 / 自我认知**
1. 为什么报考这个岗位？
2. 你认为基层工作最需要什么能力？你具备吗？举例。
3. 如果这次没考上，你会怎么办？
4. 有人说年轻人考编制就是求安稳，你怎么回应？
5. （压力题）"你的专业跟岗位不对口，我们为什么要你？"

**F. 其他题型**（部分省份涉及）：情景模拟（直接进入角色劝说）、主题演讲（1 分钟准备）。

### 作答框架要求（复盘时对照）

- 综合分析：表态定调 → 多角度分析（背景/原因/影响）→ 对策 → 适度升华防假大空
- 组织计划：目的理解 → 前期准备（人财物、调研）→ 实施（关键环节+预案）→ 复盘总结
- 应急应变：轻重缓急排序 → 控制 → 解决 → 上报与善后
- 人际关系：阳光心态/自我反思 → 主动沟通 → 工作为重 → 总结提升
- 通用扣分点：套话开头（"领导把这个任务交给我是对我的信任"）、要点重复、对策空洞无主体、超时被掐断、明显背模板与题目脱节。

### 复盘环节的追问迁移

本场全部答完后，复盘时按点评需要回放："第 2 题你说的对策部分，**如果**考官追问'谁来落实、怎么保证不烂尾'，你怎么接？"——把追问做成压力加练，训练"答案经得起下钻"，但不污染考场规则。

## 形式二：结构化小组（税务、海关等系统现行主流）

流程：抽签确定 ABC 序（如 3 人组）→ 按序轮流答题（每题每人 2–3 分钟，同题按 A→B→C）→ 互评环节（依次点评其他两人答题）→ 回应环节（被点评者逐一回应）。

考核点：
- 答题质量（同结构化标准）
- **点评质量**：既指出真问题又给建设性建议；只夸不批 = 零分点评；批而无据 = 树敌。
- **回应姿态**：对合理批评大方承认+补充，对曲解礼貌澄清；防御性过强直接出局。

**轮次细则（模拟必须照此执行，防止演成三人闲聊；各地顺序略有差异，用户说明当地公告顺序时以其为准）**：
- 答题轮：每题按序作答，同题内 A→B→C 连续答完再进下一题，每人每题 2–3 分钟（配额 = 字数 ÷ 200 + 90 秒思考）。
- 点评轮顺序固定：A 评 B、C → B 评 C、A → C 评 A、B；每人点评限时 2 分钟。
- 回应轮按被点评顺序逐一回应（B → C → A），每人限时 2 分钟，期间其他人不得插话。
- 全程考官零互动；每环节超时立即"时间到"。播报格式："【点评轮】A 号考生，请依次点评 B、C 两位（限时 2 分钟）"。

模拟方式：声明"本场你是 B 号考生"，模拟扮演 A、C 两位考生（A 中规中矩、C 有一处明显瑕疵供用户点评），用户先答、再按轮次细则做点评与回应，最后按三项考核点复盘。

## 形式四：教师编专项（试讲 / 说课 / 答辩）

教师编的核心不是结构化问答，是课堂教学能力考核。三种形态按当地公告组合：

### 试讲（10 分钟无生课堂，最主流）
- "无生"上课要**眼里有学生**：提问后停顿、模拟学生回答、走位板书、当堂反馈。
- 环节必须完整：导入（1–2 分钟，抓人）→ 新授（核心知识+互动设计）→ 练习巩固 → 小结 → 布置作业。
- 模拟方式：让用户报学科与学段，现场出课题（如语文《背影》第二课时、数学勾股定理的应用、英语现在完成时）；用户试讲后按五个观测点点评。
- **观测点与能力边界（诚实口径）**：①目标达成只评结构层——目标是否明确陈述、环节是否围绕目标组织；学科课标正确性（学段目标、知识点深度）**模型不下断言**，交给下面的自查量表；②环节完整、③互动真实感（提问-停顿-反馈循环是否出现）可评；④板书只能评结构设计不能评书写；⑤时间控制按字数估算（10 分钟 ≈ 1800–2200 字，÷200 口径）。
- **试讲自查量表（发给用户对照打勾，补上模型评不了的维度；AI 只做结构层点评）**：
  - [ ] 教学目标含行为动词（了解/理解/掌握/运用），且当堂可观察
  - [ ] 导入 90 秒内进入课题，与目标相关
  - [ ] 互动形成"提问—停顿—反馈"闭环，全程至少 3 次
  - [ ] 练习分层（基础题 + 提升题各至少 1 道）
  - [ ] 小结回扣教学目标，不跑题
  - [ ] 板书结构化（主板书呈现知识框架，副板书放演算/生字）
  自查结果与 AI 结构层点评（环节完整度、时间估算、互动密度）合并进报告；课标正确性由用户对照本学段课标自查，模型不下断言（守则见 SKILL.md）。

### 说课（5–10 分钟，说给同行听）
- 固定框架：说教材（地位与作用）→ 说学情 → 说教学目标（知识/能力/情感三维）→ 说教法学法 → 说教学过程（重头）→ 说板书设计。
- 大忌：把说课讲成试讲（说课是"讲怎么教、为什么这么教"，不是"教"）。
- 学科教材分析（如该课在本单元的地位）不确定时按 SKILL.md 专业正确性守则：给"查对应学段课标/教师用书哪一节"的路径，不代编课标结论。

### 结构化答辩（试讲后，考官可提问，此环节允许追问）
- 常考：为什么当老师、课堂突发处理（学生顶撞/睡觉/玩手机）、新课标理解、双减政策认识、班主任情境（家长投诉、学生矛盾）。
- 非师范生零经验分支：坦诚未系统训练过教学 + 展示家教/助教/支教等替代经历 + 表达已在学课标和优秀教案。

## 出题策略

- 形式确认遵循 SKILL.md 配置确认总规则：半句并入开场白（"你报考公告写的是普通结构化、结构化小组、无领导还是教师编？没的话我按普通结构化开考。"），不独立成轮。
- 普通结构化按岗位类型选题组：执法类偏 C 类情境、综合管理类偏 A/B、基层乡镇偏 C/D。
- 一场覆盖 2–4 个题型，同类型不超 2 道，接近真实套题。

## 本场景评分侧重（六维，见 scoring-and-feedback.md）

内容质量 25%、逻辑结构 20%、语言表达 20%、临场应变 15%、证据 10%、岗位匹配 10%。
证据维在本场景指"可核验支撑"（同全局定义）：对策有没有具体落实主体与步骤、有没有政策/数据/实际做法做支撑，而不是空喊"加强监督"。
重点观察：审题准（问什么答什么）、要点分层、机关实务感、时间控制、模板化程度。

**路由注意**：国网、烟草、铁路、电网、地铁等国企招聘不是公务员结构化（半结构化+专业题），走 references/soe.md。
